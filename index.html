現代遊戲 Elo 與隱分 MMR 機制 — LLM Wiki 知識庫

從 1960 年代西洋棋的經典 Elo 公式出發，深入解析 Glicko-2、微軟 TrueSkill 2、Riot Games 與 Valve 的雙軌制牌位設計，以及現代商業遊戲面臨的炸魚偵測與 EOMM（參與度優化配對）爭議。

Page 1：核心概念與名詞字典

在理解現代多人競技遊戲的積分運作前，必須先釐清系統背後的五個核心術語：

  • 配對系統（Matchmaking）：遊戲伺服器根據玩家實力、網路延遲（Ping）與排隊時間，將多位玩家分配至同一場對局的自動化演算法。
  • 隱藏積分（MMR, Matchmaking Rating）：系統在後台用來評估玩家「真實實力」的隱藏數值，直接決定你會遇到什麼程度的對手與隊友。
  • 表面牌位（Visible Rank / LP / RR）：顯示在玩家個人資料上的段位標籤（如白金、鑽石、大師），主要提供視覺成就感與賽季進度目標。
  • 評分偏差 / 不確定度（RD / σ）：系統對你目前 MMR 準確度的信心程度。新帳號或久未遊玩的玩家不確定度高，每場勝負的積分變動幅度會特別劇烈。
  • 炸魚（Smurfing）：高段位玩家刻意註冊新帳號（開小號）進入低段位對局虐菜的行為。

Page 2：配對演算法的演進史（Elo → Glicko-2 → TrueSkill 2）

現代遊戲配對並非單一公式，而是歷經三代數學模型的演進，逐步解決多人團隊競技的複雜度問題：

演算法世代 提出者 / 年份 核心數學邏輯 解決的痛點 代表應用遊戲
1. Elo 系統 Arpad Elo (1960) 1v1 零和賽局，透過雙方分差計算期望勝率 EA，再乘上權重 K 更新分數。 建立了量化玩家相對實力的基礎標準。 國際象棋、早期《英雄聯盟》S1～S2
2. Glicko / Glicko-2 Mark Glickman (1995 / 2001) 在積分之外新增 評分偏差（RD） 與 波動率（σ） 兩個參數。 解決「新手定位太慢」以及「老手半年沒玩實力退化卻還停在高分」的問題。 《CS:GO》、《Dota 2》（2023 升級版）、Lichess
3. TrueSkill / TrueSkill 2 微軟研究院 (2006 / 2018) 採用貝氏推論將實力視為常態分佈 N(μ, σ²)；2 代更納入個人局內表現（KDA/數據）與跨模式表現。 解決 5v5 多人團隊競技 中「單人實力拆解」與「凱瑞全場卻輸掉仍被扣分」的不公平感。 《最後一戰 Halo》、《戰爭機器 4》、《Apex 英雄》類似架構

關鍵公式與數學直覺（Elo 基礎）

期望勝率公式：E_A = 1 / (1 + 10^((R_B - R_A) / 400))
賽後積分更新：R'_A = R_A + K * (S_A - E_A)
  • 400 分差距法則：當雙方積分相差 400 分時，高分方的預期勝率約為 91%，低分方僅約 9%。
  • 爆冷門機制：賽後更新取決於「實際得分 SA（勝=1、平=0.5、負=0）」與「期望勝率 EA」的差值。低分玩家擊敗高分強敵時，(SA - EA) 接近 +0.91，會獲得極大幅度的加分。
  • K 值動態權重：新手期的 K 值通常設定較高，讓分數能快速收斂至真實區間；老手期的 K 值較低，避免單場失誤造成排位劇烈震盪。

Page 3：面子與裡子：表面牌位（Rank）與隱分（MMR）的雙軌制

以 Riot Games 旗下的《英雄聯盟（LoL）》與《特戰英豪（Valorant）》為代表，現代競技遊戲普遍將「表面牌位」與「MMR」分開計算：

  1. 為什麼要分開？（心理學與體驗設計）：MMR 變動極快且缺乏階段感；表面牌位（如聯盟分數 LP、競技評分 RR）搭配「晉級感」與「掉階保護」，能緩衝玩家連敗時的挫折感，並提供明確的賽季爬分目標。
  2. 補分與扣分機制（LP / RR 增減原理）：
    • 當 MMR > 表面牌位（隱分高於段位）：系統認為你被低估了，會啟動「補分機制」（例如贏一場 +28 LP，輸一場只扣 -14 LP），即使勝率只有 50% 也能穩定爬分。
    • 當 MMR < 表面牌位（隱分低於段位）：代表你因掉階保護而「德不配位」，系統會出現「贏少扣多」（贏 +15 LP、輸 -25 LP），直到表面牌位與隱分重新對齊。
  3. 《特戰英豪》的段位分層權重（Encounter MMR）：
    • 低～中段位（鐵牌～鑽石）：回合淨勝差（如 13:2 大勝）與個人對位擊殺（擊殺高隱分對手）權重高，讓高手快速脫離低端局。
    • 高段位（超凡入聖以上）：大幅降低個人 KDA 權重，幾乎只看勝負與回合差，防止高玩為了刷數據而不顧團隊戰術。
  4. 《Dota 2》的信心度視覺化（Rank Confidence）：Valve 在 2023 年更新中將 Glicko 的 RD 參數公開為「信心度百分比」；若玩家長期未上線導致信心度低於 30%，牌位會暫時隱藏並進入重新校準狀態。

Page 4：系統安全與現代爭議（炸魚偵測、SBMM 與 EOMM）

1. 炸魚偵測機制（Smurf Detection & Anti-Boosting）

  • 多維度行為指紋：系統不只看勝負，還會監控每分鐘傷害（DPM）、爆頭率、APM（每分鐘操作數）、視野控制與地圖熱區。
  • 快速跳段與隔離：一旦在極少場次內判定為高玩開小號，系統會大幅拉高其不確定度 σ 觸發「跳段」，或將其送入專屬的「炸魚佇列（Smurf Queue）」讓小號互相對決，保護一般新手體驗。

2. SBMM vs. EOMM 的核心衝突

比較維度 SBMM（基於技術的配對） EOMM（參與度優化配對）
核心目標 追求競技公平，讓雙方平均 MMR 相等（預測勝率趨近 50% vs. 50%）。 追求商業留存率，透過圖論模型降低玩家的流失風險（Churn Risk）。
運作邏輯 純粹依據玩家實力分佈進行對局配對。 根據 EA 與 UCLA 論文（2017），連敗 3 場（LLL）退坑率最高；系統傾向安排特定勝敗節奏（如 WLW）延長遊玩時間。
玩家體感與爭議 在大逃殺或休閒模式中，嚴格的 SBMM 會讓高手每場都像在打決賽，缺乏輕鬆感。 容易引發玩家「被系統安排連敗／連勝」的陰謀論質疑（多數大廠官方否認在排位賽使用 EOMM）。
